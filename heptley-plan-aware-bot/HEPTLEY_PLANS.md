## 4. Rule Enforcement Checklist for Development Assistants

1. **Check Plan Before Coding**: Read `PROJECT_REQUIREMENTS.md`. If plan is missing or unverified, prompt immediately.
2. **Page Count Audit**: Ensure the route structure does not exceed the plan's page quota.
3. **Feature Gatekeeper**:
   * If working on **Launch**: Reject admin panels, dynamic blogs, booking carts, or GBP setup requests.
   * If working on **Grow**: Reject custom admin dashboards and payment gateways; offer static WhatsApp checkout or propose Pro/Scale upgrade.
   * If working on **Pro**: Reject full dynamic CMS or eCommerce engines; propose Scale upgrade.
4. **Honesty Clause**: Never inform a client or developer that a feature is restricted by software architecture when it is actually a commercial plan boundary. Be transparent about plan tiers.
